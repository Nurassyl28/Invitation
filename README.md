# Invitation

Локальный старт Next.js версии:

```bash
npm install
npm run dev
```

После этого открой `http://localhost:3000`.

Проверки:

```bash
npm run typecheck
npm run build
```

Сейчас в проекте есть:
- Next.js 15 / React / TypeScript приложение
- профессиональная главная страница
- отдельный каталог шаблонов
- конструктор приглашения с live-preview
- блок цен
- FAQ
- кабинет пользователя
- публичная страница приглашения
- админ-панель для платежей и шаблонов
- responsive layout
- базовая интерактивность для фильтров, поиска, preview и мобильного меню

Дальше сюда можно добавить:
- backend на Next.js / API / database
- Prisma-схему
- авторизацию и роли
- сохранение RSVP
- загрузку фото и чеков оплаты
